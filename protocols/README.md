# KDE Wayland protocols

`fake-input.xml` and `zkde-screencast-unstable-v1.xml` originate from KDE
plasma-wayland-protocols (`src/protocols/`, interface version 6):
https://github.com/KDE/plasma-wayland-protocols

The original copyright and LGPL-2.1-or-later license notices are preserved in
each XML. CMake generates the client bindings using wayland-scanner.
